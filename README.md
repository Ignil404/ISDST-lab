## Как устроен CI/CD

Пайплайн описан в `.github/workflows/ci-cd.yml` и запускается на **каждый push и pull request**.

| Стадия | Job | Когда | Что делает |
|---|---|---|---|
| **CI** | `test` | push / PR во все ветки | Устанавливает зависимости и запускает `pytest` с покрытием; **при провале тестов пайплайн краснеет** |
| **CD** | `deploy` | **только push в `main`** | Упаковывает библиотеку в `dist/grade-converter.zip` и выкладывает его как артефакт сборки |

**Условие деплоя:** `if: github.ref == 'refs/heads/main' && github.event_name == 'push'` — выкладка выполняется исключительно с ветки `main` и не запускается для pull request.

**Успешный деплой** = в запуске workflow на `main` появляется артефакт `grade-converter`.
