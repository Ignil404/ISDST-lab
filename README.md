# Задача 3: Банковский счёт

**Студент:** **Буслович Игнат**

## Постановка задачи

Операции: пополнение, снятие (с проверкой баланса), перевод на другой счёт, история последних N операций. Запретить отрицательный баланс.

## Структура репозитория

| Файл | Содержание |
|------|------------|
| `structural.py` | Реализация в структурном стиле (функции + словари) |
| `oop/` | Реализация в ООП-стиле |
| `oop/account.py` | Класс `Account` — баланс, история, операции над собой |
| `oop/bank.py` | Класс `Bank` — коллекция счетов, переводы |
| `oop/errors.py` | Ошибки предметной области |
| `oop/console.py` | Класс `BankConsole` — консольный интерфейс |
| `oop/demo.py` | Демонстрационный сценарий `demo()` |
| `README.md` | Этот файл |

## Запуск

Функционал (интерактивное меню):

```
python3 structural.py
python3 -m oop
```

Демонстрационный сценарий (`demo()`):

```
python3 -c "import structural; structural.demo()"
python3 -c "import oop; oop.demo()"
```
