**Студент:** Буслович Игнат

## Постановка задачи

Онлайн-запись на приём.

- **User:** выбрать врача/слот, отменить запись.
- **Tech:** сущности «врач», «слот», «запись».
- **OpenAPI:** список врачей, свободные слоты, создать/отменить запись.

**Три обязательных блока:**

1. Пользовательская документация (Markdown) — сценарии для человека без чтения исходников.
2. Техническая документация (Markdown) — архитектура, структура репозитория, запуск, ключевые решения.
3. OpenAPI / Swagger — спецификация API предметной области (7 операций), плюс минимальный mock-сервер-заглушка.

## Обзор проекта

Учебный веб-сервис онлайн-записи в поликлинику. Пациент находит врача по специальности, просматривает свободные слоты приёма, записывается и при необходимости отменяет запись. Реализация — намеренно минимальная заглушка (in-memory mock-сервер на Python без зависимостей): документы и API-спецификация являются основным результатом работы.

| Сущность | Суть |
|----------|------|
| **Врач** (`Doctor`) | специалист поликлиники: ФИО, специальность, кабинет |
| **Слот** (`Slot`) | 30-минутный интервал приёма конкретного врача в конкретный день |
| **Запись** (`Appointment`) | бронь слота на пациента; статусы `booked` → `cancelled` |

## Запуск

```bash
python3 api/server.py        # сервер: http://127.0.0.1:8000
```

- Swagger UI: <http://127.0.0.1:8000/docs>
- Raw-спека: <http://127.0.0.1:8000/openapi.yaml>

Подробнее — в [tech.md](docs/tech.md#запуск).
