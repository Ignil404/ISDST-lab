# Лабораторные задачи: Настройка простого пайплайна CI/CD для учебного проекта

**Цель:** для небольшого учебного проекта настроить пайплайн непрерывной интеграции и доставки (CI/CD): автоматический запуск тестов при изменениях и простой шаг деплоя (публикация артефакта, GitHub/GitLab Pages или скрипт «учебного» деплоя).

---

## Требования к реализации

Каждый студент получает **одну** задачу (номер задачи соответствует номеру в журнале). Нужно подготовить **учебный мини-проект** по своей теме и настроить для него CI/CD:

1. **Проект с тестами** — реализовать небольшой модуль/сервис по постановке и покрыть его **автоматическими тестами** (хотя бы несколько осмысленных проверок: unit/API/smoke — на выбор стека).
2. **CI** — описать пайплайн (GitHub Actions и/или GitLab CI), который при `push` / Merge Request **сам запускает тесты** и падает при их провале.
3. **CD (упрощённо)** — добавить шаг деплоя: публикация на GitHub/GitLab Pages, выгрузка артефакта сборки, либо запуск учебного скрипта `deploy` (например, копирование в каталог `public/` / имитация выкладки с логом). Деплой может быть только с ветки `main` (или по тегу) — это нужно явно указать.
4. **Документация** — в `README.md` описать, как устроен пайплайн, как запустить тесты локально и как проверить статус CI.

### Общие правила

- Стек на выбор: Python, Node.js/JavaScript/TypeScript, Java, C# и т.п. Объём проекта — учебный MVP (не продакшен).
- Пайплайн должен быть **воспроизводимым**: конфигурация лежит в репозитории (`.github/workflows/*.yml` или `.gitlab-ci.yml`).
- Тесты должны реально проверять логику задачи (не один «пустой» assert без смысла).
- Деплой — упрощённый и безопасный: достаточно Pages, артефакта или mock-скрипта; **не требуется** аренда серверов и облачных секретов сверх того, что даёт учебный GitHub/GitLab.
- Секреты (если понадобятся) — только через механизмы CI (Variables / Secrets), не хранить пароли в коде.
- Репозиторий **публичный** (или доступный по ссылке без запроса доступа). Желательно добавить badge статуса пайплайна в README или приложить скриншот успешного прогона.

### Формат сдачи

Ответ студента — **ссылка** на открытый репозиторий (GitLab / GitHub), в котором есть:

| Файл / элемент | Содержание |
|----------------|------------|
| Исходники проекта | Код по теме задачи |
| Тесты | Автоматические тесты, запускаемые в CI |
| Конфиг пайплайна | `.github/workflows/*.yml` и/или `.gitlab-ci.yml` |
| Шаг деплоя | Pages / artifact / `deploy`-скрипт — по выбору, но явно в пайплайне |
| `README.md` | Постановка + **фамилия и инициалы** + описание пайплайна (badge/скрин — по желанию) |

Пример шапки `README.md`:

```markdown
# Задача N: <название>

**Студент:** Иванов И.И.

<сюда скопирована постановка задачи из этого файла>

## Как устроен CI/CD
...
```

Рекомендуемые разделы: структура проекта; как запустить тесты локально; стадии пайплайна; что считается успешным деплоем; ссылка на Actions/Pipelines.

Ссылка на репозиторий отправляется преподавателю.

## Список задач

### 1. Калькулятор стипендии по баллам

Модуль: по среднему баллу и порогам возвращает размер стипендии. Напишите тесты на граничные значения. CI запускает тесты; CD публикует простую HTML-страницу с описанием правил (Pages) или артефакт отчёта.

---

### 2. Валидатор студенческого email вуза

Функция проверки корпоративного email по правилам домена/формата. Тесты: валидные и невалидные адреса. Пайплайн: test → деплой короткой документации API/функции на Pages или в `dist/`.

---

### 3. Конвертер оценок (5-балльная ↔ ECTS)

Библиотека преобразования оценок. Unit-тесты на таблицу соответствий. CI на каждый push; CD — сборка артефакта (wheel/zip) или публикация README-сайта на Pages.

---

### 4. Генератор паролей для учебных учёток

Модуль генерации пароля по политике (длина, классы символов). Тесты политики. Пайплайн тестирует и «деплоит» CLI-справку / статическую инструкцию (Pages или artifact).

---

### 5. Счётчик посещаемости (процент по списку отметок)

Функции расчёта % посещаемости и статуса «допуск». Тесты на пороги. CI + деплой простой страницы с примерами расчёта.

---

### 6. Парсер расписания из CSV

Чтение CSV пар (день, время, предмет) и выборка на дату. Тесты на корректный разбор и фильтр. CD: выкладка примера CSV + отчёта тестов как артефакта.

---

### 7. Мини-сервис коротких ссылок (in-memory)

API или модуль: создать короткую ссылку, получить исходный URL. Тесты основных сценариев. CI; CD — mock-deploy скрипт, пишущий «версию» в `deployed/VERSION`.

---

### 8. Калькулятор индекса массы тела (ИМТ) с категориями

Функции расчёта и классификации. Тесты категорий. Пайплайн: tests → публикация одностраничного калькулятора на Pages (статика) либо артефакт.

---

### 9. Фильтр списка книг библиотеки

Поиск/фильтр по автору, году, наличию. Unit-тесты. CI обязателен; CD — статическая демо-страница каталога или JSON-артефакт выборки.

---

### 10. Проверка сложности пароля (score)

Модуль оценки силы пароля и текстовых рекомендаций. Тесты шкал. Пайплайн test + deploy документации на Pages.

---

### 11. Таймер помодоро (логика интервалов)

Модуль: работа / перерыв / длинный перерыв по счётчику сессий. Тесты переходов состояний. CI; CD — артефакт сборки или Pages с описанием алгоритма.

---

### 12. Учёт долгов по лабораторным

Структура «студент → список несданных лаб»; операции add/close/count. Тесты. Пайплайн и простой деплой отчёта/страницы статуса.

---

### 13. Конвертер единиц (длина/масса) для лабораторных измерений

Набор конверсий с тестами точности (допуск погрешности). CI; CD — публикация справочной таблицы на Pages.

---

### 14. Генератор номеров студенческих билетов / зачёток

Формат номера по правилам (год, факультет, порядковый). Тесты валидации и генерации. Mock-deploy или Pages с спецификацией формата.

---

### 15. Мини-квиз: проверка ответов на тест

Модуль сопоставления ответов с ключом, подсчёт баллов. Тесты. CI на MR/push; CD — выкладка набора вопросов как статики или артефакта.

---

### 16. Нормализатор ФИО

Функции: обрезка пробелов, капитализация, проверка «фамилия имя». Тесты краевых случаев. Пайплайн test → deploy краткой доки.

---

### 17. Калькулятор дедлайнов сдачи работ

По дате выдачи и числу дней — дата дедлайна; флаг «просрочено». Тесты с фиксированными датами. CI + Pages/artifact с примерами.

---

### 18. Система бейджей достижений (учебная)

Правила выдачи бейджей по событиям (сдал лабу, помог в ревью и т.д.). Тесты правил. Пайплайн и деплой списка бейджей (JSON/HTML).

---

### 19. Упрощённый markdown→HTML для заметок лекций

Минимальный конвертер подмножества Markdown (заголовки, списки, код). Тесты на фикстурах. CI; CD — публикация сконвертированных заметок на Pages.

---

### 20. Rate limiter для учебного API (in-memory)

Ограничение числа запросов на ключ за окно времени. Тесты лимитов. CI; CD — mock-deploy с записью конфига лимитов в артефакт.

---

### 21. Калькулятор стоимости печати в типографии вуза

Прайс + расчёт по числу страниц/цветности. Тесты тарифов. Пайплайн test → Pages с прайсом или zip-артефакт.

---

### 22. Валидатор ISBN / инвентарного номера издания

Проверка контрольной суммы / формата. Тесты валидных и битых номеров. CI + деплой справочной страницы.

---

### 23. Очередь задач (FIFO) с приоритетом

Структура данных: обычные и срочные задачи. Тесты порядка извлечения. Пайплайн; CD — артефакт или Pages с диаграммой поведения.

---

### 24. Мини-логгер с уровнями (DEBUG/INFO/ERROR)

Модуль фильтрации сообщений по уровню. Тесты. CI; CD — выкладка примера логов как артефакта после успешного теста.

---

### 25. Генератор QR-payload для пропуска на мероприятие

Формирование строки payload (id, timestamp, подпись-заглушка) и её разбор. Тесты round-trip. Пайплайн + Pages с описанием формата.

---

### 26. Статистика оценок группы

Среднее, медиана, доля «неудов» по списку оценок. Тесты. CI; CD — публикация HTML-отчёта (сгенерированного скриптом) на Pages или как artifact.

---

### 27. Кэш с TTL (учебная реализация)

In-memory cache: get/set/expire. Тесты истечения срока. Пайплайн test → mock-deploy скрипт «выкладки» версии кэша.

---

### 28. Сервис «случайная тема для доклада» с исключениями

Выбор темы из списка без повторов (и с чёрным списком). Тесты детерминированного режима (seed). Полный CI/CD: автотесты на каждый push и деплой статической витрины тем (Pages) либо артефакта списка.

---

## Критерии проверки (ориентир)

| Критерий | Что смотрят |
|----------|-------------|
| Проект | Мини-реализация соответствует теме задачи |
| Тесты | Есть осмысленные автоматические тесты; в CI они реально запускаются |
| CI | Конфиг в репозитории; пайплайн краснеет при падении тестов |
| CD | Есть понятный шаг деплоя (Pages / artifact / mock-скрипт) |
| README | Постановка + ФИО/инициалы + описание пайплайна и локального запуска |
| Воспроизводимость | По README можно понять, как проверить статус сборки в GitHub/GitLab |
