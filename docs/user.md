# Руководство пользователя: запись к врачу в поликлинике

**Что это.** Учебный веб-сервис онлайн-записи в поликлинику: вы находит врача по специальности, выбираете свободный слот (30 минут) и записываетесь на приём. Если планы изменились — запись можно отменить, слот освободится для других.

Ниже описаны сценарии «как это сделать». Каждому шагу соответствует операция API из [`openapi.yaml`](../openapi.yaml) — так пользовательский текст и спецификация говорят на одном языке.

---

## Доступ к сервису

Сервис — учебная заглушка, запускается локально одной командой:

```bash
python3 api/server.py
```

- Интерактивная документация со «своими» кнопками: <http://127.0.0.1:8000/docs> (Swagger UI).
- Приветственная страница: <http://127.0.0.1:8000/>.

В «настоящей» поликлинике этот же фронтенд был бы частью сайта регистратуры или мобильного приложения; здесь все действия выполняются через API.

## Кому подходит

- **Пациенту** — записаться к участковому или узкому специалисту.
- **Родителю** — записать ребёнка: в форме указывается имя того, кто придёт (например, «Буслович Тимур, 12 лет»).

Отдельной роли «регистратор» в заглушке нет: все операции доступны от имени пациента.

## Сценарий 1. Найти врача по специальности

1. Откройте список врачей: `GET /doctors`.
2. Отфильтруйте по специальности, например `GET /doctors?specialty=лор`.
3. В карточке врача посмотрите ФИО, специальность и номер кабинета — кабинет понадобится в день приёма.

Если специальность неизвестна («а к кому вообще идти?»), откройте `GET /doctors` без фильтра — увидите всех специалистов поликлиники.

## Сценарий 2. Посмотреть свободные слоты

1. Выберите врача из списка (нужен его `id`, например `doc-001`).
2. Запросите слоты: `GET /doctors/doc-001/slots?date=2026-10-26`.
3. В ответе — только **свободные** слоты со статусом `free`; занятые и прошедшие в список не попадают. Каждый слот — интервал 30 минут со временем начала и конца.

Без параметра `date` вернутся свободные слоты на все доступные дни (ближайшие два дня). Даты в прошлом слоты не выдаются.

## Сценарий 3. Записаться на приём

1. Выберите свободный слот (его `id`, например `doc-001_2026-10-26_1030`).
2. Отправьте запись: `POST /appointments` с телом:

   ```json
   {
     "doctor_id": "doc-001",
     "slot_id": "doc-001_2026-10-26_1030",
     "patient_name": "Буслович Тимур Игнатович",
     "patient_birthday": "2014-05-12",
     "comment": "болит горло третий день"
   }
   ```

   Обязательны только `doctor_id`, `slot_id` и `patient_name`; комментарий (жалоба) — по желанию.
3. Ответ `201 Created` — запись готова. Сохраните `id` записи (например, `apt-1`) — он понадобится для отмены. Слот тут же становится недоступен для других.

## Сценарий 4. Посмотреть свои записи

`GET /appointments` — вернёт все записи. Дополнительно можно отфильтровать: `GET /appointments?status=booked` покажет только активные (не отменённые).

Полезно перед походом в поликлинику: дата, время, врач, кабинет и статус.

## Сценарий 5. Отменить запись

1. Узнайте `id` нужной записи (сценарий 4).
2. Выполните `DELETE /appointments/apt-1`.
3. Ответ `200 OK` со статусом `cancelled` — запись отменена, слот снова свободен и появляется в списке свободных.

**Правила отмены:**

- Отменить можно только активную запись (`booked`); повторная отмена — ошибка `409`.
- Перенос в этой заглушке — это «отменить + записаться заново» (сценарии 5 и 3).

## Типичные ошибки

| Ситуация | Что вернётся | Что делать |
|----------|--------------|------------|
| Слот уже заняли, пока вы выбирали | `409 Conflict` — «слот уже занят» | Вернуться к списку слотов и взять соседний |
| Слот в прошлом | `422 Unprocessable Entity` — «время приёма уже прошло» | Выбрать более поздний слот |
| Неверный `doctor_id` или `slot_id` | `404 Not Found` | Проверить идентификаторы по спискам `/doctors` и слотов |
| Отмена уже отменённой записи | `409 Conflict` — «уже отменена» | Ничего делать не нужно |
| Забыли обязательное поле (`patient_name`) | `422 Unprocessable Entity` | Дозаполнить тело запроса |

## FAQ

**Нужна ли предоплата?** Нет, в учебной заглушке оплата не предусмотрена.

**Можно несколько записей?** Да, ограничений по количеству активных записей нет.

**Что взять с собой?** Паспорт и полис; номер кабинета — из карточки врача (поле `office` в ответе `GET /doctors/{doctorId}`).

**Что если врач не выйдет на приём?** В заглушке отмены «от клиники» нет; в рабочей системе пациент получил бы уведомление, а запись перенеслась бы или отменилась автоматически.

**Почему время в формате 10:30+03:00?** Все времена — в часовом поясе поликлиники (Europe/Minsk, `+03:00`), формат ISO 8601. Это защищает от путаницы при записи из другого региона.
