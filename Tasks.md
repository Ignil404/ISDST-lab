# Лабораторные задачи: Проектирование и программирование - структурный и объектно-ориентированный подходы

**Цель:** на одной предметной задаче сравнить структурный и объектно-ориентированный стили реализации.

---

## Требования к реализации

Каждый студент получает **одну** задачу (номер задачи соответствует номеру в журнале). Нужно выполнить её **дважды**:

1. **Структурный стиль** — функции/процедуры + данные (структуры, словари, массивы). Логика живёт в функциях; данные и поведение разделены.
2. **ООП-стиль** — классы с инкапсуляцией состояния и методов. Ответственность распределена по объектам предметной области.

### Общие правила

- Язык на выбор: Python, Java, C#, JavaScript/TypeScript, ... (один язык для обоих вариантов).
- Оба решения решают **одну и ту же** постановку задачи и дают одинаковый по смыслу результат.
- Ввод/вывод — консольный или через простой интерактив в начале программы.
- Без внешних библиотек (кроме стандартной библиотеки языка).
- Код должен быть читаемым: понятные имена, краткие комментарии там, где без них неочевидно «почему».
- В каждом варианте — небольшой демонстрационный сценарий (несколько примеров входных данных).

### Формат сдачи

Ответ студента — **ссылка** на открытый репозиторий (GitLab / GitHub), в котором есть:

| Файл | Содержание |
|------|------------|
| `structural.*` (или `structural/`) | Реализация в структурном стиле |
| `oop.*` (или `oop/`) | Реализация в ООП-стиле |
| `README.md` | Полный текст постановки своей задачи + **фамилия и инициалы** сдающего |

Пример шапки `README.md`:

```markdown
# Задача N: <название>

**Студент:** Иванов И.И.

<сюда скопирована постановка задачи из этого файла>
```

Репозиторий должен быть **публичным** (или доступным по ссылке без запроса доступа). Ссылка отправляется преподавателю.

## Список задач

### 1. Калькулятор оценок студента

Хранить список оценок (числа). Реализовать: добавление оценки, средний балл, максимальная/минимальная оценка, количество оценок ниже порога (например, < 4).

---

### 2. Список покупок

Хранить товары: название и цена. Реализовать: добавить товар, удалить по названию, сумма чека, самый дорогой товар, поиск по подстроке названия.

---

### 3. Банковский счёт

Операции: пополнение, снятие (с проверкой баланса), перевод на другой счёт, история последних N операций. Запретить отрицательный баланс.

---

### 4. Библиотека книг

Книга: название, автор, год, статус (доступна / выдана). Операции: добавить книгу, выдать, вернуть, найти по автору, список доступных.

---

### 5. Температурный журнал

Записи: дата (строка) и температура. Операции: добавить измерение, средняя температура, дни с температурой выше порога, день с минимальной температурой.

---

### 6. Очередь в поликлинику

Пациент: ФИО и номер талона. Операции: записаться в конец очереди, вызвать следующего, посмотреть кто следующий, размер очереди, найти позицию пациента.

---

### 7. Учебное расписание дня

Пара: предмет, время начала, аудитория. Операции: добавить пару, удалить по предмету, найти пару в заданное время, список пар по возрастанию времени.

---

### 8. Склад товаров

Товар: артикул, название, количество. Операции: приход, расход (не уходить в минус), остаток по артикулу, товары с остатком ниже порога, общий объём единиц на складе.

---

### 9. Игровой рейтинг

Игрок: ник и очки. Операции: добавить/обновить игрока, топ-K по очкам, поиск по нику, среднее число очков, игроки с очками ≥ порога.

---

### 10. Конвертер валют

Хранить курсы валют к базовой (например, к BYN). Операции: задать/обновить курс, конвертировать сумму A→B через базу, список доступных валют.

---

### 11. Управление задачами (TODO)

Задача: текст, приоритет (1–3), статус (открыта / закрыта). Операции: создать, закрыть, список открытых, фильтр по приоритету, количество закрытых.

---

### 12. Парковка

Места с номерами; машина — номерной знак. Операции: занять свободное место, освободить место, найти место по номеру машины, число свободных мест.

---

### 13. Журнал посещаемости

Студент и отметки за N занятий (присутствовал / отсутствовал). Операции: отметить занятие, процент посещаемости, список прогульщиков (ниже порога %), кто не пропускал.

---

### 14. Корзина интернет-магазина

Позиция: название, цена, количество. Операции: добавить/изменить количество, удалить позицию, итоговая сумма, количество уникальных позиций.

---

### 15. Геометрические фигуры на плоскости

Поддержать как минимум круг и прямоугольник: площадь и периметр. Операция: из набора фигур выбрать фигуру с максимальной площадью и вывести её тип и значение.

---

### 16. Телефонная книга

Контакт: имя, телефон, email. Операции: добавить, удалить, найти по имени, найти по фрагменту телефона, вывести все контакты по алфавиту.

---

### 17. Система скидок

Товар с ценой; правила: скидка по купону (%), скидка от суммы чека. Операции: добавить товары в заказ, применить купон, рассчитать итог со скидкой и без.

---

### 18. Тайм-трекер

Активность: название и длительность в минутах за день. Операции: добавить запись, суммарное время, активность с максимальным временем, доля каждой активности в % от дня.

---

### 19. Голосование

Кандидат: имя и число голосов. Операции: зарегистрировать кандидата, отдать голос, лидер, распределение голосов в %, проверка ничьей.

---

### 20. Фильмотека

Фильм: название, год, жанр, рейтинг. Операции: добавить, найти по жанру, фильмы с рейтингом ≥ порога, средний рейтинг по жанру, самый старый фильм.

---

### 21. Учёт расходов

Трата: категория, сумма, дата. Операции: добавить трату, сумма за период (по строковым датам достаточно лексикографически, если формат YYYY-MM-DD), сумма по категории, категория с максимальными тратами.

---

### 22. Игра «камень-ножницы-бумага» (серия партий)

Режим игрок vs компьютер (случайный ход). Вести счёт серии, историю партий, объявить победителя при достижении N побед. Показать статистику ходов игрока.

---

### 23. Шифр Цезаря (упрощённо)

Для латиницы и/или кириллицы: шифрование и расшифрование строки со сдвигом K. Операции: зашифровать, расшифровать, проверить что расшифровка обратима на тестовой фразе.

---

### 24. Матричный калькулятор (2×2 или N×N небольшое)

Операции над двумя матрицами: сложение, умножение, транспонирование одной матрицы, определитель для 2×2. Ввод матриц с консоли.

---

### 25. Система бронирования столиков

Столик: номер, вместимость. Бронь: имя гостя, время, число гостей. Операции: забронировать (подобрать столик ≥ числа гостей), отменить бронь, список свободных столиков на слот.

---

### 26. Чат-лог (локальный)

Сообщение: автор, текст, время. Операции: отправить сообщение, последние N сообщений, сообщения автора, поиск по подстроке в тексте.

---

### 27. Учёт электроэнергии

Показания счётчика по месяцам (число). Операции: добавить показание (новое ≥ предыдущего), расход за месяц, средний расход, месяц с максимальным расходом.

---

### 28. Простая ролевая боевая система

Два персонажа: имя, здоровье, атака, защита. Ход: урон = max(1, атака − защита), уменьшение HP. Симулировать бой до победы одного; вывести лог раундов и победителя.

---

## Критерии проверки (ориентир)

| Критерий | Что смотрят |
|----------|-------------|
| Полнота | Обе реализации покрывают пункты постановки |
| Стиль | В структурном — акцент на функциях; в ООП — на классах и ответственности объектов |
| README | Есть постановка + ФИО/инициалы |
| Запуск | Скрипты запускаются, демо-сценарий понятен |
| Читаемость | Имена и структура кода позволяют разобраться без автора |
